# Release kit: "Sometimes I Think Slow" (DistroKid → Spotify, Apple Music)

Everything DistroKid asks for, ready to upload. The media files are git-ignored like all media in this repo.

| File | What it is |
|---|---|
| `Sometimes I Think Slow - Travis Fischer.wav` | The master: the Suno V6 final take (`audio/suno/final-take.wav`), unaltered. 48 kHz / 16-bit stereo, 3:02, −15.8 LUFS. |
| `cover.jpg` | 3000×3000 RGB. The approved poster (`video/poster.png`) outpainted to a square with nano-banana-pro: more overpass above, dry pavement below, and the lettering unchanged. |
| `cover-title-only.jpg` | The same scene with the wall repainted to read only "SOMETIMES I THINK SLOW". This is the safer upload, because DistroKid only allows cover text that matches the title or the artist name, and "FAST & SLOW" is neither. |
| `lyrics.txt` | The written lyrics, not Suno's phonetic ones: Andrej, Kahneman, Navier–Stokes and RL rather than Ahn-dray, Kah-nuh-mun, Nav-yay Stokes and R-L, with "slooow" back to "slow". The line order follows the take, so the one hook repeat Suno skipped is left out. Rebuild with `make_lyrics.py`. |
| `cover-work/` | The 4K outpaints, with a fal receipt (prompt + parameters) next to each. The chosen ones are `sits_dry2` and `sits_title2`. |
